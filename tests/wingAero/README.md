# wingAero regression support

Shared frozen-state/one-step regression runner. Only run_case.py is retained because fluxContinuity, gmresEarlyExit and highOrderNewton use it. Supply an external --case and --library-dir. Project wing sweeps, preparation scripts and results were archived.

Project CFD validation belongs in `../../../validation/hisa_adflow_comparison`; large runtime cases belong under workspace `reports`.
