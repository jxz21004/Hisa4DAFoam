# limitedSnGradParity regression support

verify.py compares native/ADR frozen-state residual and derivative reports supplied in external directories. It checks primal equivalence, AD parity and directional derivative errors. Historical numerical reports are in Git history and the cleanup archive; no project result is stored here.

Project CFD validation belongs in `../../../validation/hisa_adflow_comparison`; large runtime cases belong under workspace `reports`.
