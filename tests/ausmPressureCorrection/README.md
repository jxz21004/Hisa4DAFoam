# AUSMPlusUp 压力修正不连续：复现与修复

基于本次下载仓库的提交 `1f79402`。修复文件：
`src/finiteVolume/fluxSchemes/ausmPlusUp/ausmPlusUpFluxScheme.C`。

## 已确认的问题

令 `m` 为压力修正前的面马赫数，`d` 为 `MDiff`。原代码在修正跨过零点时返回 `m + 0.2*d`，其他情况返回 `m + d`。这使修正后的面马赫数在 `m+d=0` 和部分 `m=0` 处发生有限跳变。

例如固定 `d=-0.1`：

| 输入 m | 修复前结果 | 修复后结果 |
| --- | --- | --- |
| 0.099999999 | 0.079999999 | -0.000000001 |
| 0.100000001 | 0.000000001 | 0.000000001 |

输入变化仅 `2e-9`，原结果跳变约 `0.08`；缩小输入扰动不会消除跳变。该量用于质量通量，故这不是日志误差或浮点舍入问题；也会使跨分支有限差分与当前分支的自动微分不一致。测试直接提取并编译源文件里的压力修正表达式，不另外重写原算法。

## 修改

移除仅在流向反转时启用的 0.2 系数，连续加入完整压力修正：

```cpp
Mach_1_2.ref() += MDiff();
```

保留 MDiff 本身、重构、压力通量及其余离散方式。此修改会改变触发旧分支时的计算结果，可能需要重新建立部分气动力回归基准，不能直接宣称原有全算例结果不变。
