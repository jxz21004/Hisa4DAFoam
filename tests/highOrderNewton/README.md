# 高阶导数与带线搜索的修正试验

保持 wVanLeer 对流重构和修复后的黏性功，使用一阶初始化后恢复高阶所得的停滞状态。
原始残差 L2=41231.0786、最大值=17566.9735；这些是固定定义的残差，不是 HiSA 日志中的动态归一化指标。

check_parity.py / check_derivatives.py 首先发现普通版与 ADR 的 limitedSnGrad 系数初始化差异。
修复与证据见 ../limitedSnGradParity/README.md；验证通过后才执行下面的修正。

correct.py 使用 6Nc 耦合残差（U/p/T/nuTilda），状态列按 normalizeStates 缩放；
采用稀疏直接 LU 求解，不使用 HiSA 的 5Nc GMRES/LUSGS。使用固定行尺度残差的
Armijo 回溯和 p/T/nuTilda 正值保护。每一步重新评估实际残差；因此属于独立实验求解器，
不能把它的表现当成生产 HiSA 伪时间算法已经修复。固定行尺度目标下降也不保证每项原始残差单调下降。

两种矩阵模式：

- 默认：DAFoam calcdRdWT(0) 的着色前向有限差分矩阵，步长 1e-7。
- --geometric：独立按两圈单元邻接构造所有 6×6 块的依赖图，按互不重叠的行支持着色，
  中心有限差分步长 1e-8。本例 47 种单元颜色，每颜色分 6 个状态分量扰动。

两圈依赖适用于本次静态网格和局部格式，不能无验证推广到任意边界或非局部模型。
独立矩阵同样做中心方向差分检查；两种模式的差分步长和差分方式不同，单凭总体误差差异
不能断言差异全部来自着色或依赖图缺项。

默认矩阵在初态的方向误差约 3.323e-3，线性求解本身残差约 6.94e-11，
但线搜索仅接受约 2.35e-8 的步长，第二步失败，实际残差几乎没变。
独立矩阵初态方向误差为 3.250e-6，首步接受 0.0625，次步接受 0.5。
这些结果支持继续排查组装矩阵；尚未直接验证具体缺失的矩阵条目。

运行时指定隔离案例（含 final_state.npz）和已验证的新库：

```sh
python tests/highOrderNewton/correct.py --case CASE --library-dir LIBDIR --iterations 3 --geometric
```

所有保存结果均需通过真实残差验收，不能以 LU 成功或线搜索接受代替稳态收敛。
此处不验证稳态气动梯度，也未覆盖并行计算。

独立矩阵前三步全部接受，L2 残差 41231.0786 → 19687.7743，最大绝对值 17566.9735 → 7636.9603。
续算阶段由该检查点开始，重新确定并固定行尺度，结果单独保存。
